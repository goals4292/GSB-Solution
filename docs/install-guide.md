# 설치·활용 가이드

## 누가 설치해야 하나요?

- 회사 담당자가 공유 서버 링크로 이용: 설치 불필요. [사용 안내](user-guide.md)만 확인합니다.
- 연구실 서버를 운영: [Linux 서버 설정](server-setup.md)을 수행합니다.
- 회사 Windows PC에서 직접 실행: [Windows 설치](windows-setup.md)를 수행합니다.

## 권장 전달 순서

1. 전달용 ZIP을 서버에 풀고 가상환경과 의존성을 설치합니다.
2. `data/raw/gsb_input.xlsx`를 확인합니다. 이 배포본에는 분석에 사용한 추가 데이터 사본이 들어 있습니다.
3. `python scripts/verify_notebook.py`로 전체 노트북을 시험합니다.
4. 서버 비밀번호를 만들고 JupyterLab을 시작합니다.
5. ngrok 또는 기관의 HTTPS 접속 경로를 연결합니다.
6. 외부 Windows PC에서 로그인·전체 실행·다운로드를 확인합니다.
7. GitHub 주소, 사용자 안내서, 노트북 링크를 담당자에게 전달합니다.

## 전달 상태

코드·안내서·노트북을 제공한 상태이며, 실제 서버 배포와 외부 URL 발급은 운영자가 해야 합니다. README의 링크 안내는 서버 주소 발급 후 갱신합니다. 예시 회사의 ngrok 주소를 GSB 접속 주소로 사용하지 않습니다.

## 이번 배포본 검증 범위

원본 기준 279 LOT·217쌍·r 약 −0.091 재현, 노트북의 모든 코드 셀 순차 실행, 결과 저장, 원본 해시 보존, 6개 데이터 처리 테스트를 확인했습니다. JupyterLab 비밀번호 로그인과 노트북 페이지 HTTP 접근도 확인했습니다. 검증 환경의 커널 소켓 제한 때문에 별도 커널에서의 전체 실행 및 외부 Windows 브라우저 실행은 서버에서 최종 확인해야 합니다. `python scripts/verify_notebook.py --in-process`는 소켓 제한 환경의 코드 검증용이며 실제 커널 시험을 대체하지 않습니다.
