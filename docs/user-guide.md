# 회사 담당자 사용 안내

## 접속과 실행

1. 운영자가 보낸 노트북 링크를 Edge 또는 Chrome에서 엽니다.
2. ngrok 안내 페이지가 보이면 `Visit Site`를 누릅니다. 공유 링크 전체를 열면 비밀번호 입력 없이 접속됩니다.
3. 파일이 자동으로 열리지 않으면 왼쪽에서 `GSB_quality_analysis.ipynb`를 두 번 클릭합니다.
4. 화면 위 **Run → Run All Cells**를 클릭합니다. 커널 선택창이 나오면 `Python 3 (ipykernel)`을 선택합니다.
5. 각 코드 셀 왼쪽의 `[*]`는 실행 중입니다. 숫자로 바뀌면 해당 셀 실행이 끝난 것입니다.
6. 맨 아래 **분석 완료**가 표시되면 표와 그래프를 확인합니다.

셀 하나씩 확인하려면 셀을 클릭하고 ▶ 버튼 또는 `Shift+Enter`를 누릅니다. 처음에는 위에서 아래로 순서대로 실행합니다. 다시 실행할 때는 **Kernel → Restart Kernel and Run All Cells**를 사용할 수 있습니다.

## 결과 내려받기

마지막 셀의 결과 폴더를 열어 CSV·PNG·HTML을 선택하고 우클릭 **Download**로 저장합니다. HTML 보고서의 그래프를 오프라인에서 보려면 같은 결과 폴더의 PNG도 함께 내려받아야 합니다. CSV는 Windows Excel에서 열 수 있도록 UTF-8 BOM으로 저장합니다.

## 추가 데이터 사용

같은 형식의 최신 엑셀을 왼쪽 `data/raw` 폴더에 업로드합니다. 기본 파일명은 `gsb_input.xlsx`입니다. 기존 원본은 운영자가 별도 보관한 뒤 교체합니다. 노트북 분석 자체는 원본을 수정하지 않습니다. CSV 또는 다른 이름을 사용하려면 운영자가 노트북 1단계의 `INPUT_FILE` 한 줄을 바꿉니다.

## 오류 대처

| 화면 상황 | 조치 |
|---|---|
| 사이트에 연결할 수 없음 / ngrok offline | 운영자에게 서버와 ngrok 실행 여부 확인 요청 |
| 로그인 화면이 나옴 | 전달받은 전체 링크에서 token 부분이 빠지지 않았는지 확인 |
| FileNotFoundError | `data/raw/gsb_input.xlsx` 업로드 여부 확인 |
| 필수 컬럼·LOT 블록 오류 | 입력 양식이 달라진 상태이므로 운영자에게 파일 전달 |
| 중복 LOT 오류 | 동일 품번·LOT 행이 중복되었는지 확인 |
| NameError | 중간 셀만 실행했을 수 있으므로 전체 셀 실행 |
| ModuleNotFoundError | 운영자에게 설치환경 및 커널 확인 요청 |
| 실행이 오래 멈춤 | 같은 셀을 반복 클릭하지 말고 운영자에게 오류 화면 전달 |

한 서버는 한 담당자가 순차 실행하는 용도입니다. 동시에 여러 사람이 편집·실행해야 하면 운영자가 사용자별 환경을 구성해야 합니다.
