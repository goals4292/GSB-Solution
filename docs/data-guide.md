# 입력 자료와 분석 기준

## 현재 엑셀

`[GSB솔루션] 추가데이터_부품 생산 실적 정리(1).xlsx` 사본을 `data/raw/gsb_input.xlsx`로 제공합니다. 3개 연도 시트의 LOT 블록을 읽습니다. 기존 양식의 성형·전조 생산수량 및 불량수량, O~R열의 측정일과 치수 위치를 사용하며, 헤더와 블록 구성이 다르면 중단합니다. 새 양식으로 바뀌면 열 위치를 추정해서 분석하지 말고 표준 CSV로 변환합니다.

지원 엑셀 시트는 24년·25년·26년 명칭입니다. 다른 연도·양식은 표준 CSV를 사용합니다. 품번은 각 시트의 B5에서 읽습니다. 본 규격은 대표 품번 11404 10806P에만 적용하며 다른 품번을 혼합하지 않습니다.

## 표준 CSV

`data/templates/lot_measurements.csv`는 헤더만 있는 빈 양식입니다. 한 행은 동일 품번의 LOT 한 개입니다. 모든 행을 포함한 최신 파일을 업로드합니다. 여러 파일을 자동 병합하지 않습니다.

| 컬럼 | 의미 |
|---|---|
| part_no / lot | 품번 / LOT 식별자 |
| sheet_year | 집계 연도, 실제 측정연도와 다를 수 있음 |
| forming_date / thread_date | 성형 / 전조 측정일, YYYY-MM-DD |
| forming_diameter_mm | 성형 전조하경, mm |
| thread_diameter_mm | 전조 나사외경, mm |
| forming_produced / thread_produced | 각 공정 생산수량, EA |
| forming_defects / thread_defects | 각 공정 기록 불량수량, EA |

모르는 값은 빈칸 또는 `-`로 남기며 0으로 입력하지 않습니다. 식별자와 집계연도는 필수이며 나머지 결측은 보존합니다. 동일 품번·LOT가 중복되면 중단합니다. 개별 샘플 자료는 이 LOT 양식에 억지로 넣지 말고 샘플 식별자를 포함한 별도 구조로 확장해야 합니다.

## 해석 기준

- 전조하경 규격 9.06~9.10 mm, 나사외경 규격 9.76~9.97 mm. 양 끝값은 규격 내이며, 작업표준서의 현행 적용 여부는 기업 확인이 필요합니다.
- 두 치수가 모두 있는 LOT만 피어슨 계산에 사용합니다. 같은 LOT 행의 값이라는 뜻이며 같은 제품을 전후 측정했다는 뜻은 아닙니다.
- 연도 집계는 시트 연도, 추세 그래프는 실제 전조 측정일을 사용합니다.
- 불량수량 합계는 기록된 값만 합산합니다. 모두 결측이면 합계를 결측으로 표시합니다.
- PPM은 생산수량이 양수이고 불량수량이 기록된 동일 LOT들에서 `불량수량 합계 / 생산수량 합계 × 10⁶`으로 계산합니다. 생산수량의 정의가 총수량인지 양품수량인지는 기업 확인이 필요하므로 계산 PPM은 잠정 지표입니다.
- 치수 이탈 건수는 기록값 수이며 불량품 수량이 아닙니다. 전조 불량수량의 불량유형은 확인이 필요합니다.
- 불량예측·위험 임계치 자동학습은 구현하지 않았습니다. 규격 이탈 실측값과 대표성 확인 후 별도 검증이 필요합니다.

## 재현 기준

제공 엑셀 기준 총 279 LOT, 전조하경 236건, 나사외경 254건, 연결 217쌍, 전체 Pearson r 약 −0.090688입니다. 새로운 자료를 넣으면 결과가 달라질 수 있으며, 검증 스크립트의 기준값 대조는 원본 해시가 일치할 때만 적용합니다.
